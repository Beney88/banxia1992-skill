# 风格与机会结构

## 从资料中提炼的风格

来源对应《补涨猎人》§5、§6、§7、§8，详细证据等级见 source-map.md。

- 主攻短线低位接力，尤其一进二；整理稿转引其演讲称打板居多、二板占比较高。这是历史偏好，不是适用于所有年份的统计规律。
- 不擅长的交易方式主动删掉。其放弃首板是个人适配经验，不等于首板天然负期望；亦不能把“约600只”误解为必须每天交易。
- 首先考虑流动性在哪里。高位抱团时，资金未必流向低位；指数强弱与低位连板赚钱效应可以背离。
- 旧主线没有明显竞争方向、承接仍在时，可提出延续假设。惯性只是待验证的市场假设，不是物理定律；利空后上涨不证明利空越大越该满仓买。
- 分仓但不必平均；用真实反馈调节风险暴露。个人能力、环境、题材相关性与执行约束比“看好程度”更重要。
- 接受卖飞，回避情绪化补票、亏损后加码、非主流随手单。环境不适配或自身不能专注时，停止新开仓。

## 先做风格诊断

这些是将原文转成可观察证据的方法，不是半夏1992公开过的固定打分公式。

| 当前特征 | 应检查的证据 | 对此模式的含义 |
| --- | --- | --- |
| 低位接力有延续 | 前日首板/二板样本的次日表现、晋级与断板损失、题材梯队是否有承接 | 可以进一步筛选，仍需个股风险审查 |
| 高位核心抱团 | 核心反复走强而低位跟风频繁冲高回落 | 不机械挖低位；缺独立新催化则等待 |
| 大容量趋势主导 | 涨幅和成交集中于趋势核心，连板赚钱效应弱 | 此技能可能不适配；不把所有均线突破硬包装为一进二 |
| 退潮/负反馈 | 断板跌停、低位也无承接、冲高回落扩散、赚钱效应明显恶化 | 优先暂停新开仓，管理已有风险 |
| 修复或潜在切换 | 原下跌结构减弱，新方向出现可验证催化、扩散和承接 | 只作候选节点，不能事后命名后倒推“必买” |

样本比较需同口径、同观察时点，并报告覆盖范围。只有若干新闻或涨幅榜时，不宣称完成全市场扫描。主线判定结合板块广度、持续性、成交和核心反馈，不凭单只涨停或热搜。

## 两条路线

### A. 仍有效主线内的低位补涨

要回答：

1. 已有主线为什么仍能吸引流动性？核心与同梯队是否支持，是否已有更强竞争方向？
2. 候选与主线是否存在可核验业务/事件关联？如果只是市场题材标签，明确它不是业绩兑现。
3. 相对梯队和题材周期是否真的偏早？低股价、低估值或刚刚涨停都不能单独证明低位。
4. 为什么它可能获得承接，而不是任意滞涨跟风？辨识度、实际成交、换手过程和同组竞争至少要给出可观察依据。
5. 若核心走弱、同梯队失败、候选自身失守预期，何时撤销计划？

典型合格表达：主线仍活跃，候选属于低位接力观察池；只有其自身完成预设承接确认、同组反馈不恶化且可合理成交时，才考虑风险预算内试错。不是“龙头涨了很多，所以它必补涨”。

### B. 新催化下的题材切换

区分三个阶段：消息存在 → 市场开始响应 → 有足够证据形成可交易的方向。三者不是同义词。

- 核验消息发布时间、出处及新增信息量；旧闻重发不是新催化。
- 看响应是否超出单一股票，旧主线是否仍吸走流动性；旧主线退潮不意味着任意新题材会接棒。
- 新方向若只有一字板、买不到的领涨或零散脉冲，不能虚构可执行机会。
- 承认切换存在失败路径：一日游、回流旧主线、整体退潮。触发失败则取消，不用“节点稀缺”替代验证。

## 入场形式与预期差

资料同时出现“半路/竞价”说法和“绝大多数打板”归纳，不能合成统一机械买点。分析时标明本次属于竞价观察、半路确认还是打板观察，并匹配数据要求。

- **竞价观察**：09:25前只做临时快照。最终价量及相对前收表现要核验；大额挂单可变、封单不等于成交，不能猜排队可成交。
- **半路确认**：说明相较盘前预期哪些证据改善、什么价格/结构失效；“提前抢二板”本身不构成优势。
- **打板观察**：检查触板、换手、回封与同组反馈的实际过程；只有日线不能判断首封时间、开板次数或封单稳定性。封板后不可合理成交就放弃模拟成交假设。
- **预期差**：先写事前预期及依据，再写实际偏离。事后上涨不能反证当时“超预期”；不把高开一律视作超预期。

“站稳几分钟”“放量几倍”“竞价涨幅区间”只能是明确标注、可调整的本次预案参数，不能捏造为原作者口令。若用5分钟K线确认，明确完整K线；若用盘中价确认，承认噪声与回撤风险。

## 退出与不做

按 risk-and-execution.md 区分可卖旧仓与锁定新仓。退出围绕原假设不成立、流动性改变和风险预算，而不是强求卖最高。

- 原预期是快速延续，但实际明显弱于自身与同组预期：重新评估或按事前计划降低可卖风险，不用加仓掩盖失败。
- 题材和个股结构仍成立：不因“涨多了”或不宜新追就武断要求清空旧仓；分别讨论持有和新买。
- 退潮、中位跟风、非主流且无法独立解释、情绪失控、亏损后急于扳回：停止寻找“下一只翻本股”。
- “中位”是周期、梯队、辨识度和承接的组合，不等于固定第三板；“不做龙头”是该风格选择，不是所有龙头都不能买的普遍结论。
