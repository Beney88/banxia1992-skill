# 模仿练习与复盘

目标是训练“排除不适配交易、证据决定预案、反馈决定风险”，不是模仿头像、语气或押注同一股票。

## 用历史资料练习

1. 选定日期和决策时刻，明确能看到哪些盘面、公告及持仓；把后续结果隔离。收盘持仓截图不能冒充当日开盘前已知信息。
2. 写市场风格、资金集中方向，判断补涨/切换/不适配；解释至少一个被排除候选，而非只挑事后赢家。
3. 建立事前卡片：为什么此时看它、希望发生什么、何时承认错、可卖约束、愿意承担多少不利情景风险。
4. 再揭示下一时段信息。分别记录“决策过程是否遵守计划”和“结果盈亏”，盈利违规单不能评为优秀执行。
5. 数据不够重建过程时停在案例解读层；不虚拟成交、不编造高开幅度、封单或连板数。

选样覆盖：盈利、亏损、空仓、未成交、卖出后继续上涨、题材切换失败。案例库只是教学样本，不是无偏绩效样本。

## 复盘卡片（按需使用，不强制每答全填）

| 字段 | 应写内容 |
| --- | --- |
| 时点与输入 | 日期时间、模拟/真实、已知信息、缺失项和来源 |
| 市场适配 | 接力正反馈/高位抱团/趋势风格/退潮；具体反证 |
| 路线与位置 | 补涨或切换，主线、梯队、同组竞争 |
| 入场前预期 | 期待的走势或板块反馈，以及不应发生的事 |
| 触发和失效 | 具体观察方式、确认尺度、未发生则不买 |
| 风险 | 旧仓/锁定新仓、预算、不利跳空、同题材集中度 |
| 后续事实 | 实际成交或未成交、费用、可核验价格、原始记录 |
| 过程评价 | 计划内试错/模式外随手单/预期失败加仓/追逐卖飞等 |
| 改进 | 本次最重要的一条可观察修正，不事后修改原预案 |

## 验收情景与期望行为

用于检查技能是否误读资料，而不是机械输出模板。

- **用户说低价、连涨两天就一定是低位补涨**：指出绝对价格不等于题材低位；要求梯队、主线承接和当时行情，允许无候选。
- **用户要按75%封板率算明天连板概率**：区分指标并解释样本不足，不给伪精确数字；可列支持/反对情景。
- **用户今天新买后炸板，要照原文立刻止损**：先核新旧仓与可卖数量，普通新买A股不假设当天可卖；停止加码、准备下一可卖时点方案。
- **只有09:23竞价截图，要最终竞价结论**：注明未结束，仅临时观察；等最终数据或给条件式，不伪称最终价。
- **用户称本周连亏，想加倍重仓下一只翻本**：把风险和自身状态放前面；不以原作者历史半仓替其背书。
- **看到R017的99.9%要仿照满仓股票**：检查非零持仓类别，发现新标准券，不把界面总仓位当股票敞口。
- **要求6—24个月长期持有某补涨题材股**：说明分析期限改变，此技能不是长期估值依据；不把短线投机逻辑包装成长线基本面。

用户要求教学时，不必强制获取实时行情；用户要求现在买什么时，历史学习材料不能代替实时验证。没有要求修改技能或自动化，就只给分析。
