# 资料来源、证据等级与冲突

## 公开版本的范围

本仓库发布的是可复用的分析流程与风控参考，不包含原始交易截图、OCR结果、账户记录或完整案例库。公开内容不构成对任何交易者身份、账户真实性、交易收益或策略胜率的独立认证。

如需核验某个历史案例，应先取得相应原始截图或一手来源，确认日期、信息可得时点、证券身份、截图字段含义和交易制度。无法回看原始证据时，只能注明为转述或未核实信息。

## 证据分层

- **原始画面可见事实**：仅描述来源画面确实显示的字段；截图真实性未获券商流水认证。不能从账户快照推导未显示的动机、实际成交顺序、首封时间或完整盈亏。
- **转引观点**：标明“资料转引的观点”；未核验原始音视频或原帖时，不称为已认证原话。
- **第三方归纳**：媒体、评论者和整理表仅作待核背景，不直接变成交易规则。
- **分析提炼**：本技能的流程、观察指标、反证和风险预算方法属于整理后的应用，不冒充作者发布过的固定参数体系。

重复转述同一事件不构成独立证据。核对人物或机构时，不能把同名账号、其他投资机构或无关主体混为一谈。

## 常见冲突与处理原则

| 材料问题 | 处理原则 |
| --- | --- |
| 个人经历中出现固定打板、仓位或止损口令 | 当作个人历史经验，不直接套用于用户；先核对交易品种、当时规则与用户的可卖仓位 |
| 封板率、盈利率、收益倍数等数字缺少口径 | 不互相替代，不编造次日连板概率；没有完整样本、费用与成交假设时不作绩效结论 |
| 账户资产变化缺少出入金、费用和其他品种记录 | 不据截图认证净值、复利或策略收益 |
| 截图中的成本、现价、浮盈和清仓行混用 | 不把现价或参考盈亏当作已实现成交结果 |
| “满仓”截图包含非股票项目 | 先核验资产分类，不等同于股票风险敞口 |
| 交易日期、股票名称或代码存在矛盾 | 保留不确定性；不擅自纠正年份或补配代码 |
| 材料中止损口令与现行交易制度冲突 | 以适用的交易制度及可卖数量为准，普通A股新买仓位不得假设当日可卖 |

## 新案例的记录要求

新增案例应记录来源、时间、决策时点能看到的信息、后续反馈、可卖限制和风险边界；同时覆盖失败、空仓与未成交案例。缺少原始记录时，停止在定性解读，不重建虚构成交。
